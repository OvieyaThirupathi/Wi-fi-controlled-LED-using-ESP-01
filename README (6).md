  
 **WIFI CONTROLLED LED USING ESP-01**

**1\. Aim**

To control an LED using an ESP-01 WiFi module through wireless communication.

**2\. Problem Statement**

Conventional LED control requires physical switches or direct connections. A wireless method can provide remote control without using a physical switch.

**3\. Proposed Solution**

The ESP-01 WiFi module connects to a WiFi network and receives control commands. Based on the command, the LED is switched ON or OFF.

**4\. Components Required**

ESP-01 WiFi Module

LED

Resistor

Breadboard

Jumper wires

USB-to-Serial adapter/programmer

Power supply

**5\. Circuit Working**

The ESP-01 connects to the WiFi network and receives the required command. When an ON command is received, the ESP-01 activates the LED. When an OFF command is received, the LED is switched OFF.

**6\. Procedure**

1\. Connect the ESP-01 to the required power supply.

2\. Connect the LED through a suitable resistor.

3\. Connect the ESP-01 to the programming interface.

4\. Upload the required program.

5\. Connect the module to WiFi.

6\. Send ON and OFF commands and observe the LED.

7**. Applications**

Smart home systems

IoT projects

Wireless lighting control

Remote monitoring systems

Automation projects

**8\. Advantages**

Wireless control

Compact system

Easy to operate

Useful for IoT applications

Reduces physical wiring for control

**9\. Result**

The LED is successfully controlled wirelessly using the ESP-01 WiFi module.

**10\. Conclusion**

The project demonstrates the use of WiFi communication for controlling an LED and introduces the basic concept of IoT-based automation.

**11\. Project Demonstration**

The project demonstrates WiFi connection through ESP-01 and wireless control of the LED between ON and OFF states.
